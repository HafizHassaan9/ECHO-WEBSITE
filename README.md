# Hassan bin Imran — Video Editor & Cinematographer Portfolio

Personal portfolio website for Hassan bin Imran (Chakwal, Pakistan): video editing, mobile cinematography, photography and Canva.

Built from the ECHO portfolio template by [Jishnu Mondal](https://github.com/Jishnu09-siuu).

## Run locally

```
npm start
```

Then open http://localhost:8080

## Things to replace with your own files

- `assets/hero_portrait.png` — your photo (a PNG with a transparent background looks best)
- `Project Images/video-editing-sample.jpg`, `cinematography-sample-1.jpg`, `cinematography-sample-2.jpg` — a screenshot of each video's thumbnail (keep the same file names)

## Where the content lives

- `index.html` — name, about, experience, services, contact
- `flex-carousel.js` — featured work (video links)
- `works-wheel.js` — cinematography wheel (video links)
- `experience-section.js` — experience section labels
